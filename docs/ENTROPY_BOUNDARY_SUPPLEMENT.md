# 熵试跑：已有答案的补充边界协议

日期：2026-10-10。适用范围：a10 固定20题、38个E/T配对点的76份已保存输出。
这是看到原严格评分覆盖不足后制定的**事后探索性补充**，不是采集前预注册结果。
原严格分析保持 `not_estimable`，不覆盖原 `grading.json`、`analysis-input.json` 或其他证据。
本补充不生成答案、不使用GPU、不增加题目、不调参。

## 已知问题与适用边界

原评分器在答案正文含思考标记时拒绝判分。本批36份未决输出在重复 `</think>`
前有完整boxed；结构可提取不意味着数学正确。采集器在E/T端点都注入同一
`FINAL_PREFIX`，并明确记录该前缀之后的答案正文，因此可以另行定义正文结束边界。
此规则不适用于普通完整推理转录，也不追溯修改q001或其他旧实验。

## 先固定所有span，再判分

1. 只接受 `answer_boundary_confirmed is True` 且
   `boundary_policy == known_injected_final_prefix_v1` 的保存输出。
2. 结构函数只接收原文及上述边界信息，不接收gold、E/T身份、题号、置信度、熵或收益。
3. 若出现 `<think>` 或 `</think>`，以首次出现的位置为正文结束。
   仅当此前恰有一个完整顶层boxed、没有未闭合boxed且原结构提取器返回
   `extracted` 时接受此前span；其他情况保持未决。不在标记之后寻找替代答案。
4. 若没有上述标记，原文不变，交由原判分器执行已有规则。
   其他不受支持的思考标记仍由原判分器拒绝。
5. 对全部76条执行同一规则，先保存无gold的边界决定、原文hash、字符span、
   源码hash和协议hash；该文件落盘后才运行数学判分。缺失或身份不一致即停止。
6. span未变的保留原判分，不重复调用判分器制造版本或超时漂移；新span使用
   同一Math-Verify版本、严格参数、超时和gold。原gold需复核的仍需复核。
   保存全部补充分数及与原严格分的逐条变化；任何原已决标签变化必须报告。

## 锁定分析与报告

只复制分析输入中的 `actions.E/T.error` 与 `grading_status`，其他字段逐项保持一致，
包括原始答案、模型特征、实测耗时、题目顺序与全部候选。边界裁决和截取文本另存。
尤其不能因评分正文截短而减少原完整E/T的执行成本或token计数。
复用原分析器、4×4按题分折、ridge alpha=1、最少训练4题、60000ms主错误代价
及30000/120000ms敏感性；不改变样本、不根据结果选设置。

无论结果如何，保留原严格结果并列报告补充覆盖、B/H/常数预测误差、预算匹配收益、
按题探索性区间和局限。补充结果不能升级成独立确认性证据；没有稳定增益就不扩GPU。
解释标签时区分固定256-token继续思考的收益、追加观测引起的选择改变、熵的增量预测力。

入口：`scripts/supplement_entropy_boundaries.py prepare` 先生成无gold决定，
`grade` 再用固定评分环境产生全新补充目录。原分析器随后读取新输入。
