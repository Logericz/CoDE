# 共同在线数值参考契约

冻结日期：2026-10-08。适用范围：当前共同在线后端的新增有界验收；不回写旧结果，不表示论文主实验已通过。依据 `manuscript/coling2027/EXPERIMENT_PLAN.md` 第 5.1–5.3、6.3 节区分原版离线、共同在线和诊断 oracle。

## 两种问题，分别记录

1. **在线 probe 实现一致性**：真实 prompt prefill 后逐 token 接纳已保存推理，构造主 KV。新 probe 与固定上游 `calcu_max_probs_w_kv()` 使用同一份主 KV、同一 trial prefix、模型、精度和 attention。要求 token IDs、原始概率、confidence、结束标记 exact 一致；各 probe 前后主 KV、logits、私有及全局 RNG 指纹不变。任一失败即停止该验收。
2. **跨计算路径敏感性**：在相同 token 前缀上，另调用固定原函数重新计算完整前缀，保留所有原始概率和与在线路径的差异。它是原版离线参考，不是同 KV 实现一致性的替代。报告 confidence、有效性、置信停止、退化分数及停止谓词的变化；不得据有限病例宣称全局等价或无影响。

旧 `gpu-validation-001` 的完整前缀 exact 失败保持失败；本契约不放宽容差，也不把新门槛通过重命名为旧门槛通过。前缀分段计算已经被定位为差异所在，但具体数值机理尚未证明。

## 本轮固定范围

- 只复用 q001 的 2 个、q002 的 3 个已保存前缀；不重新生成 q001 寻找 2008。
- 置信、退化历史按题和计算路径分别维护，候选时钟按保存顺序记录。q001 只有 2 点，退化分数为零；q002 有 3 点，可以检查该保存历史上的退化判定。
- 使用默认冻结停止规则，并单独记录计划中的阈值敏感性；所有有限点诊断均不等于完整轨迹或质量验证。
- q002 首个保存前缀补充 0/1/2 次 probe 隔离，各最多续写 64 tokens。保留过去 q001 的隔离证据。
- 同 KV 与隔离通过后才继续有限在线分支烟测；未覆盖的实际早停、自然 EOS、自然结束思考后的预算边界逐项列出。
- 自然结束分支可另用固定合成题的真实模型采样验证，必须单列题目来源；没有 EOS 的运行记为未覆盖，不强制 token 或在同轮中换种子寻找通过。
- 32K 合成缓存容量检查只证明该构造路径的显存/上下文可行性，不证明自然生成跑满 32K，也不作为在线速度结果。

全部方法共享模型、主采样、候选定义、probe、最终答案和计时边界。只允许显式指定日程改变观测和停止机会。保留完整执行分母、失败与独立判分。先完成有界验收和正式配置开发试跑的实测预算，再扩大到校准/选参/测试矩阵。
