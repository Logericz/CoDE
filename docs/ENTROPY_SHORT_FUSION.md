# 同一短试答上的置信度与熵融合

日期：2026-10-11。用户决定先验证融合本身及融合方式。本轮只复用已有缓存，
不扩题、不生成答案、不使用SSH/GPU、不改旧评分或旧分析器。
这是已暴露开发集上的固定对照，不是独立确认性实验或两篇原方法的完整复现。

## 问题、样本与共同目标

固定原20题roster、原4个题级外折与seed=20261010。38条合法E/T配对记录进入分折池，
每折仅拟合该折训练题。主评价为短试答实际满21 token且未结束的27点/13题，
其成员只由短阶段信息决定，不用长试答、答案或收益筛选。
同时报告全部38点/19题及其余11个短试答已终止点；后两者不是独立验证集。

E为当前前缀固定补答；T为最多继续256主token再执行相同补答，补答上限128 token。
训练目标直接为delta=L_E-L_T，其中L_a=实测剩余时间+lambda*答错标记。
主lambda=60000ms，30000/120000ms为固定敏感性；分数>0选T，否则E。
保持原ridge alpha=1；填补、缺失标记、缩放和截距只拟合训练折，不搜索阈值或融合权重。
这次没有长选择器、追加动作或价值预测器f，因此不扣长probe成本。

## 固定信号组

共同上下文Z：prefix_tokens、short_probe_tokens、short_ended_with_think。

| 组别 | 维度 | 输入 |
| --- | ---: | --- |
| Z | 3 | 共同上下文，仅作控制 |
| C | 7 | Z + short_confidence、相邻confidence变化、D_short、short_prob_slope |
| H | 5 | Z + short_entropy_mean、short_entropy_slope |
| CH | 9 | Z + C的4个信号 + H的2个信号 |

H不能读取置信度、D或置信度历史；C不能读取熵；全部模型都不能读取long特征、答案、
成本或题号作为输入。CH必须逐点复现上一轮compact short g的保存分数和动作。
原解析器会核验缓存的长短前缀一致性，但本轮特征、主样本成员及决策只读短阶段信息。

## 如何融合

主候选CH为早期特征融合：一次拟合9维输入预测delta。每折每lambda的Z/C/H/CH
各只拟合一次，下面规则复用同一份外测C/H分数，无额外训练或调参：

- late_avg：两分数等权平均，>0继续，否则退出。
- late_agree：C/H均主张退出才退出，否则继续。
- late_either：C/H任一主张退出就退出，否则继续。

后两者的“保守/积极”只描述退出倾向，不承诺答案更正确。全部规则完整报告，
不把结果最好的一条追认为主方法。另有训练折delta均值、always_E、always_T三种基线，
共10个可执行策略。已知答案后选择E/T或在C/H动作中选择较好者仅作为诊断上界。

## 评价与解释

唯一主比较为主lambda、27点上CH相对C的累计决策损失差；CH相对H是必要辅助比较。
同时报告正确数、可避免错误、剩余实测时间、理想动作额外损失、逐题平均损失。
所有融合相对C的动作翻转单列：错误→正确、正确→错误、对错不变的省时/增时。
MAE/MSE只对有delta分数的组作辅助分析，不替代决策收益。

按题重采样2000次（seed=20261911）给配对平均损失差的探索性区间，固定已拟合模型，
不是训练/方案选择不确定性的完整区间。另列删除单题后差值范围，不重训、不据此选方案。
未决评分保持缺失；空集或训练题不足4题记not_estimable，不补题、不补造0。

共同短probe实测成本单列，可用于缓存账目加总；它不影响同一缓存策略之间的损失差。
采集时已计算熵，不能用本轮缓存推断线上添加熵或预测器的额外耗时为0。
分类器推理和真实端到端速度尚未测量，累计秒等价损失不能写成GPU加速。

继续研究的正向信号：CH主设置相对C和H均减少决策损失且不增加可避免答错，并检查
敏感性及单题影响。只改善MAE、不改善动作，不算决策收益；只胜Z或常数也不证明融合。
本轮不根据结果修改特征、规则、阈值、分折或原始评分；不自动启动未见题实验。
