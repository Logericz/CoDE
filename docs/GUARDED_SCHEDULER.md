# Guarded：第一个实际修改调度行为的开发候选

2026-10-09。实现：[guarded.py](../src/online_methods/guarded.py)。
CLI 名称：`codestop-guarded`。原 `adaptive` 保持为对照。
这份设计基于已暴露的十题开发结果，不是原实验前预注册，也尚无新颖性结论。
本轮先固定下面的默认规则再做整批候选回放，不做参数搜索。

## 问题与改动

旧 Adaptive 在这十题的18次继续决策中均遇到 incomplete probe，退回逐点探测。
此外，旧 `min(h_signal, h_cost)` 的成本上界也可能把间隔压到1。
有效但未完成的试答已有有限置信值，且当前共同规则本来就让它参与D历史。
候选假设是：用这部分已查询信号判断“下一个点是否值得探测”，可能减少冗余探测。
不完整试答的高置信值仍不能触发置信早停；共同停止规则保持原样。

新候选同时改变两处：允许 valid incomplete 进入调度公式；以短间隔和风险保护
代替旧成本 min。它是新的调度启发式，不能当作原 Adaptive 的修bug，也不能将
任何收益单独归因于移除 incomplete 保护。未来正式比较需要对应消融。

## 第一版的精确规则

输入仅为当前已查询 probe、上一次有效观测、有效历史数、当前D、候选编号差与
已记录成本状态；没有题号、gold、未来置信度、未来token间距或跳过点的观测。

1. 共同控制器先判断是否停止。已经停止就不调用调度函数。
2. 若观测无效、有效历史未满3条、历史/变化率不可用、计时异常或置信下降，取h=1。
3. 对可以继续判断的状态，计算停止余量与近期变化率：

   ```text
   m = min(max(r-c, 0), max(1-D/τ, 0))
   u = max(abs(c-c_prev)/Δj,
           max(D-D_prev, 0)/(τ*Δj),
           0.001)
   ```

4. 默认保护带m0=0.05。若m≤m0，或2u≥m−m0，取h=1；否则取h=2。

h=2表示跳过一个合法候选点，在下下个候选点再探测。它不是跳过两个tokens，
也不能保证时间或token延迟有固定上限。条件的含义是：只有离停止边界较远、
按最近变化率推算两候选内仍未进入保护带时才跳过。未来变化可能突增，因此
该启发式没有“不漏停止”的保证。

`margin_m0` 复用已有配置，默认0.05；`ACTIVITY_FLOOR=0.001`也复用既有值。
间隔固定为1或2，通用配置中的`h_max`、`beta`不参与此候选计算。
`rho`保留在日志中，异常成本状态仍恢复dense，但数值大小不作为间隔上界；
`h_cost`为null。未经查询的点不进入D历史。

## 还有哪些设计路线

| 路线 | 可观察的作用机制 | 主要代价/失败情形 | 次序 |
| --- | --- | --- | --- |
| 短间隔+风险保护 | 稳定且远离边界时少做probe，风险升高恢复逐点 | 信号会突变；收益可能很小 | 本轮实现 |
| 候选间隔+token间隔限制 | 对很长的候选间距提前恢复查询资格 | 需要在每个合法候选处检查当前token位置；候选本身很稀疏时仍无硬延迟保证 | 第二步候选 |
| 主推理轻量信号预测探测价值 | 在付费probe前估计它是否可能改变停止决定 | 需要新信号、成本计量、校准及独立数据；不可先假定预测有效 | 后续 |
| 自适应probe长度 | 选择是否为不完整试答追加观测预算 | 改变置信量、结束率和成本，不能复用当前21-token缓存评价新输出 | 后续 |

这些是设计候选，不是已经确认的论文创新。相关工作重叠需在确定主线后定向核验；
本轮不因采用常见门控、预测或多级探测思路就主张新颖性。

## 本轮如何检验

先用共享引擎的合成测试确认真实跳过接线；再使用旧a09的同10题完整轨迹做
因果顺序回放。只向候选提供已查询点，原数据hash与当前方法源码hash分开记录。
比较Dense、旧Adaptive、Fixed-h2和Guarded默认配置，全部10题纳入，不选择好题。

观察实际查询/跳过数量、首次停止位置、主生成和probe token的部分工作量。
若新停止点没有对应的已有最终答案，质量记为未知。回放不能提供新的在线耗时。
若仍全h=1，或省probe却增加较多主生成，停止推进这版，不用改阈值来修饰本轮结果。
即使停止点相同，也只能说明缓存中同一路径的停止行为一致。

旧Dense的probe/cache平均约占总时长1.38%，调度优化的直接收益空间有限。
只有候选回放显示实际稀疏且代价可接受，才考虑新的有界GPU验收；不直接启动四卡
主矩阵。源码身份改变后，旧GPU gate必须继续拒绝冒用旧验收。

本轮结果另存 `results/guarded-candidate-20261009.md`；设计与实现的hash进入私有
`runs/guarded-candidate-20261009/` 回放产物。稿件、旧实验配置、原始答案和判分不改。
