# 熵能否预测追加试答的收益：小规模开发协议

日期：2026-10-10。用户授权：先做小规模验证，暂不扩大实验。
本文件在新GPU结果出现前固定设置。它不是CoDE/EntroCut完整方法比较，也不是论文主实验。

## 问题与对照

在已知固定短试答的置信度、token最大概率曲线和历史之后，熵是否还能预测
**追加同一试答后，退出/继续选择的净改善**？高熵、熵下降和试答完成均不是收益标签。

- B：短试答置信度、概率曲线摘要、固定短预算的CoDE退化分数D、历史、长度。
- H：B加同一短试答的全词表熵及曲线摘要。
- 两者预测完全相同的外折标签；不把含熵的选择器分数输入B。
- 固定alpha=1的ridge；不搜索模型/阈值，不训练基础语言模型。

## 固定采集范围

| 项目 | 设置 |
| --- | --- |
| 数据 | 原冻结selection120按原顺序排除整个pilot20，取前20题 |
| 用途 | 新开发暴露，不是未见主测试；冻结JSONL不改写 |
| 候选 | 每题自然思考结束/EOS/8192主token前的前3个Wait，最多60个配对点 |
| 短/长试答 | 相同主前缀、相同trial prefix、同一贪心KV分支，最多21→42 token |
| E | 当前前缀接固定FINAL_PREFIX，贪心补答最多128 token或EOS |
| T | 接受已采样的pending Wait，最多推进256主token（含Wait），然后同一个F |
| T自然结束 | 若遇think/EOS，保留该pending token记录，不接受该标记；从此前缀执行F |
| 轨迹 | 采集主轨迹不应用早停；E/T分支不能改变主KV或主采样RNG |
| 模型 | 固定Qwen3-4B revision，BF16/eager，原采样设置，单4090 |
| 随机种子 | master42/rollout0/domain entropy-value-main-v1，按原题ID派生 |
| 时限 | 全轮7200秒，每题900秒；操作之间检查，CUDA kernel不可抢占 |
| 失败 | 首个执行错误/OOM/超时停止，无自动重跑；无候选/未决不补换题 |

本轮在同一题采集多个位置是为获得历史与配对标签；它不等于部署了多步自适应策略。
T是一个固定256-token局部干预，不代表恢复到完整自然推理结束的价值。
21/42/256/128均为本次预设预算，不能由本轮最优表现反推为普遍最优设置。

## 观测与数值

`src/entropy_probe.py`是独立实验模块，不改冻结后端的`probe()`。
原21-token置信度仍使用模型原dtype、原累加顺序及原非标准归一化。
熵在独立float32分支由未作temperature/top-k/top-p处理的全词表logits计算，单位nats。
长试答不回写成一个新历史点，也不改变原D的尺度。

新协议遇EOS立即结束并标无效；旧probe遇EOS继续后标无效。
因此21-token exact parity只适用于无EOS的合法路径。实际token数≤2、非有限值等保留为无效，
不修成有利分数。已经终止或长试答没有新增token的点不能作为可追加样本，避免凭两个估计器
的有限样本差异制造虚假观测收益。

首个真实候选只做一次GPU验收：旧21与新21、21→42与直接42、主KV/logits/RNG隔离，
失败即停止。该重复工作是验收成本，不能算实验策略开销或收益。

覆盖补充（2026-10-10，采集期间）：首个候选实际在5 tokens结束，原验收只覆盖
终止路径，不能据此确认实质续写。采集结束后由`validate_entropy_extension.py`按题号/
候选号固定选择首个合法21→>21的已存点，逐token重放其已保存前缀并核对原观测、旧21、
分段42、直接42及主状态隔离。只验一个已有前缀，限900秒，不生成新E/T答案、不换样本；
若没有符合点则明确未覆盖。新增验收及其成本另存，正在运行的采集源码与计划不变。

## 标签与数据隔离

E/T最终答案分别用原严格Math-Verify协议评分，保留全部输出和已知答案边界。
原始candidate文件不回写；新增grading与analysis-input文件。
无法自动判定、异常格式及需要复核的gold均保留`error:null`，不计作错误或正确。

定义`L_a = remaining_ms_a + lambda_error_ms * error_a`。
主设置lambda=60000ms；30000/120000ms仅作预声明敏感性，不挑选最好设置替代主设置。

短选择器g_short与长选择器g_long均可使用各自当时可见的置信度、概率、熵和历史。
g_long保留短信息再添加长信息；两者预测`L_E-L_T`，正值选T，否则E。
不能由gold直接在E/T里挑赢家。

标签为`z = L(g_short) - L(g_long) - extra_probe_ms`。
追加时间包含继续分支及释放时间；已有短探测为共同已付成本。
E/T是实际执行的克隆分支成本；采集总时长包含所有分支、验收和评分。
离线选择收益不等于已部署在线节约时间，预测器自身部署开销还未测量。

按完整20题roster固定4个外折，同题各候选永不跨训练/验证边界。
每个外训练集内部再交叉拟合g产生训练z，然后拟合B/H；外测试g只由外训练题训练。
所有标准化和缺失值处理限训练折。测试题标签只用于最终评价。

## 结果与去留

保留题目分母、无候选数、无效探测数、评分未知数、真正可追加且可评分点数。
报告B/H预测误差、常数预测对照、相同追加数量下兑现的z、按题重采样的探索性区间。
外折模型共享训练题，因此bootstrap区间只描述本批数据稳定性，不当作独立确认性显著性。
样本/有效题数不足时报告不可估，不扩大样本凑结论。

本轮结束后只决定是否值得再设计下一轮，不能自动启动更多题、4卡并行或正式基准。
